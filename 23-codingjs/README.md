# CodingJS

The CodingBat problem set, as ported to JavaScript by CodingJS. Small, sharp
exercises that each turn on one idea: an off-by-one, an empty string, a rule
with one exception. The upstream prose is not open licensed, so every
statement here is written fresh and every example is computed and checked
against a reference implementation.
